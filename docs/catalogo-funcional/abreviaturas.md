Las otras expansiones son hipótesis para revisión. Una regla previa no representa una nueva aprobación. En particular, EXT incluye formas con y sin punto, pero sólo EXT. tiene expansión previa; ALUM sin punto continúa pendiente. No se interpretan CAT, KL, MHA, FEH, TW, USB ni los números de modelo como abreviaturas descriptivas.

## Criterio de aplicación

El diccionario aprobado sólo expande palabras aisladas. Conserva PVC, USB, LED, fracciones como 1/4 y códigos como 3X21X60 o BO-90. No extiende MOB a MOBIL ni ECON a ECO, y no aplica las nuevas expansiones dentro de un modelo compuesto.

`normalizeProductName` sirve para presentación. `normalizeProductNameForRoute` mantiene las reglas anteriores de los nombres usados en URL. Una fixture obtenida del código de 6909394 verifica los 1.319 slugs y los casos aprobados. Las sugerencias deben navegar con el SKU original para que la redirección existente resuelva la URL canónica.

La búsqueda conserva las coincidencias y referencias originales. Ordena primero ID/SKU exactos, luego referencia exacta; para los demás resultados prioriza el inicio del nombre, incluyendo los sinónimos existentes, antes de disponibilidad o promoción. No asigna marcas ni activa las hipótesis de esta tabla.
